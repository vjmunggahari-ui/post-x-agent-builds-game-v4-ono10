# NEON ORBIT — my agent built a game from one prompt

One prompt in, one playable game out. My AI agent built **NEON ORBIT**, a neon
orbit-ring dodger, from a single sentence — then played it to a WIN on camera.

## The one prompt

> Build me a tiny neon browser game: a ship circles a star on 3 orbit rings.
> One key jumps to the next ring out. Dodge asteroids, collect stardust,
> score 100 to win.

## Play it

Open `game.html` in a desktop browser (no network needed). **SPACE / click /
tap** jumps to the next ring out. Collect gold stardust (+10), dodge the
red-rimmed asteroids, reach **score 100 to win**. 3 shields — one hit costs
one shield. `?autoplay=1` runs the built-in bot — that is how the video's
gameplay was captured.

## The video

`video.mp4` (1280×720, 30 fps, 30.5 s) shows the prompt, the agent working
(real terminal output from the build session), the finished game played to a
WIN (score 100, 10 stardust, 2 shields left), and ends with make.fun's
referral card carrying the code `j9vvzrcw`.
